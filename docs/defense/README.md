## Пересборка

Из корня репозитория в отдельном Python-окружении:

```bash
python -m pip install -r docs/defense/requirements.txt
python docs/defense/build.py
```

Нужны шрифты DejaVu Sans в `/usr/share/fonts/truetype/dejavu` либо переменная
`EFQA_FONT_DIR` с путём к ним. Скрипт создаёт PDF, PPTX, заметки и manifest с SHA-256
каждого включённого документа. Изменяйте `slides.json` и исходные Markdown, а не
сгенерированные документы. В PDF шрифты встроены; на компьютере показа PPTX должен
быть доступен DejaVu Sans или корректный заменяющий шрифт. Для надёжного показа — PDF.

Пакет основан на `main@53c6f7b`. Нового испытания P6 при его сборке не выполнялось.
