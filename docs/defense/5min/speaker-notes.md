## Ответы на вопросы

- **На каком этапе чаще рождается брак в космической отрасли?** Открытые четыре случая этого не измеряют. В двух из выбранных случаев NASA подтвердила поставку/испытания, в двух точное место не установлено. Реальную частоту узнаем из журнала контрольных точек предприятия с сопоставимым знаменателем и экспертной атрибуцией причин.
- **Предотвратили бы мы CRS-7 / MS-04?** Не доказано. Наша камера не видит все скрытые свойства. Проект связывает применимый метод, испытание, входную деталь, операцию, решение и поздний пересмотр; эффективность проверяется пилотом.
- **Почему не готовая QMS?** QMS с полноценным аудитом может обеспечить те же свойства. Сравниваем восстановление B «тогда», полноту контроля, повторы, поздние события и ACK на конкретной конфигурации. Если проходит проще, выбираем её.
- **Что реально работает?** Синтетический P8 с API, PostgreSQL, UI и ERP-эмулятором; источники чисел — сохранённый протокол P8, это не новый запуск приложения при сборке слайдов. Физические камеры, edge и раннее сенсорное предупреждение ещё нужно валидировать.
