# Исполняемый пример улучшений PI-01

Откройте [production-preview.html](production-preview.html) локально в браузере.
Это **синтетический эксперимент**, не подключённый к производственной БД:
готовность поста, инструмент, охват партии, полезный контроль, передача смены,
тревоги, ранний сигнал и карта этапов. Кнопки показывают локальную имитацию
сигнализации. Звук появляется только после разрешающего нажатия.

[production-result.json](production-result.json) — результат запуска;
[независимые ожидания](../acceptance/production-improvements-expected.json)
написаны отдельно и проверяются pytest. Пункт 7 исключён пользователем.
Пункт 8 и подсказки по полноте B находятся в основном интерфейсе приложения.

Для регенерации в **новый** файл из `backend/`:

```bash
python -m scripts.production_improvements_demo --html /path/to/new-preview.html
```

HTML/JSON сгенерированы скриптом, вручную их не редактировать. Постоянная запись
задач/тревог, авторизация новых команд, физические сенсоры и управление реальной
лампой требуют отдельной интеграции. Предложение роли №1 и текущая граница:
[PI-01](../architecture/production-improvements-implementation.md).

Пакет защиты `docs/defense/` сохраняет снимок предыдущей поставки; обновление
его заявлений о промышленной готовности возможно только после общего review.
