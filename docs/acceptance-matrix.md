# Матрица критериев и доказательств

Состояние на 25 сентября 2026. «Готово» означает проверено указанной командой в зоне роли №2; это не оценка всего MVP. Повторяющиеся строки отраслевого и технического блоков не суммируются.

| Критерий | Артефакт роли №2 | Проверка / статус |
| --- | --- | --- |
| Производственный маршрут и режимные ограничения | `docs/first-slice.md`, `docs/camera-ai.md`, сценарии `data/` | Сценарий синтетический; консультация с заказчиком ещё нужна |
| Сквозной процесс | UI `frontend/`, первый сценарий и эмулятор | Компоненты подготовлены; реальный backend/PostgreSQL ещё не подключён |
| Пропуски, повторы, задержки | `data/scenarios.json`, `emulator/replay.py` | Генерация и порядок повторов проверены; серверное поведение проверит роль №1 |
| Защита и презентация | `docs/presentation.md`, `docs/screencast.md` | Материалы подготовлены; скринкаст и проверка целостности ожидают работающий backend |
| Дополнительные функции | Повторная обработка, несколько признаков и наблюдений в данных | Генератор воспроизводим; серверные выводы пока не проверены |
| Расширяемость и масштабирование | `integrations/adapters.py`, `docs/integrations.md` | Адаптеры проверены как чистые преобразования; нагрузка и несколько обработчиков не проверены |
| Спецификация и кодогенерация | `contracts/openapi.yaml`, `contracts/generated/models.py`, `frontend/src/generated/api.ts` | Генераторы запускаются, модели принимают все сценарные события |
| Рассинхронизация контрактов | `frontend/scripts/check-contract.mjs`, CI | Самопроверка обнаруживает удаление enum и новое обязательное поле; проверка запущенного API ожидает backend |
| Долгосрочная криптография | — | Не реализована; не заявлять баллы |
| Запуск и воспроизводимость | README, npm lock, Python генератор, CI | UI, данные и эмулятор воспроизводимы; общий Docker Compose — зона роли №1 |
| Архитектура и внешние системы | `docs/integrations.md`, `contracts/external-openapi.yaml` | Реальный обмен с эмулятором проверен на его HTTP-границе; outbox backend ожидает подключение |
| ИБ и аудит | UI не хранит ключи; передача bearer token; граница решений в контракте | Серверные права, шифрование и аудит — зона роли №1; сквозная проверка не выполнена |
| Документация | README, эти материалы и handoff | Команды и ограничения зафиксированы |
