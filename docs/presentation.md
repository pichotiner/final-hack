# Черновик презентации защиты

Слайды нужно обновить скриншотами и фактическими результатами после сквозного запуска. Ниже — текст и порядок без заявления о неготовых функциях.

## 1. Задача

Производству нужна проверяемая история изделия: от входного контроля и операций до решения ОТК и результата во внешней системе. Один признак в кадре не равен доказанной причине брака.

## 2. Маршрут данных

ERP-эмулятор → задание и справочник → события контроля/участков → backend/PostgreSQL → паспорт изделия и карточка → решение контролёра → outbox → ACK эмулятора. В демонстрации источник визуальных наблюдений синтетический; фото и собственная CV-модель отсутствуют.

## 3. Изделие и история

Показать `assembly-001`, состав `bracket-001` и `insert-001`, два участка, двух операторов и событие станка. На ленте различать `occurred_at` и `received_at`. Длительности двух операций — по 120 секунд полного времени на участке; активное время не выводится из этих границ.

## 4. Несоответствие и решение

Два наблюдения `mark-001` связаны с одной логической карточкой. Исходный сигнал, автоматическая гипотеза, решение контролёра и итог изделия отображаются отдельно. Отклонение станка — обстоятельство; подтверждённой ошибки оператора нет.

## 5. Повторы и поздние сведения

Повтор `evt-001-final` с тем же ID получает квитанцию дубля и не меняет KPI. Поздний сигнал с временем 10:02:30 перестраивает историю, сохраняет прежнее решение и требует пересмотра. Показывать только после проверки на backend.

## 6. Обмен и границы

Результат с `message_id` получает ACK эмулятора; повтор того же ID/тела идемпотентен, конфликт тела виден. Прямые vendor API 1С/Галактика/MES/КОМПАС не подключены. Камеры/ИИ описаны как проект для данных заказчика, точность не измерена.

## 7. Проверки и развитие

Показать команды CI, обнаружение несовместимого изменения контракта и отдельные ожидаемые результаты сценария. Дальше: интеграция с backend, проверка целостности, чистый запуск, пилот камер, нагрузка и восстановление. Серверную архитектуру и защиту представляет роль №1 по своим фактическим проверкам.
