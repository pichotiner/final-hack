## Что проверено в коде

- Строгий общий конверт JSON, версии и типы; привязка события к идентификатору источника, который передаёт будущий слой аутентификации.
- Точные исходные байты сохраняются зашифрованными; ключи внедряются извне. Проверены изменение ciphertext/метаданных, смена активного ключа и недоступный старый ключ.
- Восемь одновременных доставок сохраняют один исходник и одно состояние обработки. Дубликат возвращает первоначальную квитанцию; конфликт не затирает исходник.
- Ошибка создания состояния обработки откатывает исходник в той же транзакции.
- UPDATE/DELETE/TRUNCATE журнала блокируются. Ограниченная роль БД не может отключить триггеры. Привилегированное изменение метаданных обнаруживается AEAD перед подтверждением дубля.
- Позднее событие сохраняет своё время возникновения и серверное время приёма.

Проверки выполнены командами из `backend/README.md`; Ruff и `pip check` прошли. Состояние каждого события пока `unresolved`: производственные проекции ещё не подключены.

## Чего пока нет

- HTTP API, frontend и производственных моделей изделий/операций/несоответствий/решений.
- Реализованных эмулятора, генератора, адаптеров и сценарных данных.
- Формальной OpenAPI/JSON Schema спецификации и кодогенерации.
- CI, полного сквозного теста и нагрузочного испытания системы.
- Dockerfile backend и общего развёртывания приложения, интерфейса и эмулятора.
- Пользовательской аутентификации/RBAC, полного аудита, TLS, рабочего secret mount и процедуры восстановления. Реализованная защита отдельных записей не закрывает все требования ИБ.
- Пересчёта истории изделия/KPI, transactional outbox и обмена результатами с ERP.
- Готового проекта камер/ИИ и полного архитектурного описания.
- Презентации, скринкаста, результатов нагрузочных испытаний и реализованного постквантового/гибридного сценария.

Маршруты API и примеры JSON в документации не означают наличие работающих endpoints. `JsonEventCodec` проверяет только общий конверт; полная типовая валидация должна быть подключена через сгенерированные DTO. Формальная спецификация и генерация ещё не реализованы.
