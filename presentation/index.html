Внешний обмен и контракт

Проверяемые границы

ERP-эмулятор

Задание на вход, версия результата на выход, ACK по message_id. Повтор с тем же телом — duplicate; изменённое тело — конфликт.

OpenAPI 3.1

Один транспортный контракт генерирует Python и TypeScript модели. CI выявляет устаревшие артефакты и несовместимые изменения.

Примеры 1С, Галактика:ERP, MES и КОМПАС-3D — файловые адаптеры, прямых vendor API нет.
